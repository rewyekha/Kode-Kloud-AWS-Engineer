# Day 12: Attach Volume to EC2 Instance

An instance named `datacenter-ec2` and a volume named `datacenter-volume` already exist in the `us-east-1` region. Attach the `datacenter-volume` volume to the `datacenter-ec2` instance, making sure to set the device name to `/dev/sdb` while attaching the volume.

**Notes:**

* Create the resources only in `us-east-1` region.
